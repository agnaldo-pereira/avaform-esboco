# AvaForm — Plataforma de apoio à avaliação formativa

Esboço navegável para discussão na qualificação de uma dissertação de mestrado.

## Finalidade

Apresentar uma proposta inicial de organização dos cadastros, do planejamento, dos registros pedagógicos e do percurso de aprendizagem. As funcionalidades e a organização visual estão sujeitas à revisão pelo pesquisador e à investigação das necessidades docentes.

## Demonstração

- Cadastros de escolas, disciplinas, turmas e alunos.
- Contexto por escola, turma e disciplina.
- Planejamento, observação, interpretação, feedback e decisão pedagógica.
- Consulta de registros e percurso de aprendizagem.
- Sugestões predefinidas que ilustram uma assistência opcional por IA.

Todos os dados são fictícios. Não há autenticação, banco de dados ou conexão com modelos de IA. As alterações permanecem somente na página aberta e são perdidas ao recarregar. Os exemplos não constituem resultados de pesquisa.

## Versão para qualificação

Versão identificada: **12 de novembro de 2026**.

- Página principal: https://agnaldo-pereira.github.io/avaform-esboco/

O seletor de tema permite escolher Automático, Claro ou Escuro. A logo acompanha o tema e a preferência é mantida no navegador quando o armazenamento local está disponível. As logos foram fornecidas pelo pesquisador.

Para citar o material na dissertação, prefira a versão identificada. Este repositório contém somente a demonstração; não contém o texto, as referências ou os dados da dissertação.

## Executar localmente

Abra o arquivo `index.html` em um navegador atualizado. Não é necessário instalar dependências.
