# AvaForm — Plataforma de apoio à avaliação formativa

Site demonstrativo navegável para discussão na qualificação de uma dissertação de mestrado.

## Finalidade

Apresentar uma proposta inicial de organização dos cadastros, do planejamento, dos registros pedagógicos e do percurso de aprendizagem. As funcionalidades e a organização visual estão sujeitas à revisão pelo pesquisador e à investigação das necessidades docentes.

## Demonstração

- Cadastros de escolas, disciplinas, turmas e alunos.
- Contexto por escola, turma e disciplina.
- Planejamento, observação, interpretação, feedback e decisão pedagógica.
- Consulta de registros e percurso de aprendizagem.
- Sugestões predefinidas que ilustram uma assistência opcional por IA.

Todos os dados pedagógicos são fictícios. Não há autenticação, banco de dados ou conexão com modelos de IA. O perfil “prof. Agnaldo” é demonstrativo. Os exemplos não constituem resultados de pesquisa.

Os registros são guardados no armazenamento da sessão do navegador para manter a continuidade ao navegar entre as páginas na mesma aba. O fechamento da aba encerra essa sessão. Nenhum registro é enviado a um servidor.

## Páginas

- index.html: página inicial, apresentação e atalhos.
- plataforma.html: área de trabalho com cadastros, planejamento, registros e percurso.
- perfil.html: perfil demonstrativo do professor.
- assets/: estilos, preferência de tema e logos compartilhados.

Os atalhos da página inicial abrem diretamente o módulo correspondente na área de trabalho.

Abra o arquivo `index.html` em um navegador atualizado. Não é necessário instalar dependências.
